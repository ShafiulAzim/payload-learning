# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Payload-managed blog listing and detail pages with automatic slugs, categories, publication access control, filtering, and pagination.

**Architecture:** Two Payload collections own categories and posts. Server-rendered App Router pages query public posts through Payload Local API; focused reusable components render cards, filters, pagination, article content, and sidebars.

**Tech Stack:** Payload CMS 3.88, PostgreSQL, Next.js 16, React 19, TypeScript, Tailwind CSS, Payload Lexical React renderer.

**Spec:** `docs/superpowers/specs/2026-08-23-blog-design.md`

## Global Constraints

- Automatically generate unique SEO slugs; editors do not need to enter them repeatedly.
- Public visitors can read only published, non-future posts.
- Preserve layout-level global Header and Footer ownership.
- Do not add test files, commit, or push.
